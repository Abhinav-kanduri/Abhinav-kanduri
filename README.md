## What I Do

**Large Language Models (LLMs)**
- Design and deploy LLM-powered applications for enterprise use cases
- Work across SLMs vs LLMs, prompt strategies, adapters, and fine-tuning approaches
- Address hallucination, inconsistency, and determinism challenges in production

**Retrieval-Augmented Generation (RAG)**
- Build end-to-end RAG pipelines (ingestion → chunking → embedding → retrieval → generation)
- Optimize retrieval quality with semantic chunking, hybrid search, and reranking
- Evaluate systems on groundedness, faithfulness, and relevance
- Design for freshness, traceability, and explainability

**LLMOps / MLOps**
- Productionize LLM systems with versioned prompts &amp; datasets and continuous evaluation
- Implement monitoring for drift, quality decay, and prompt regressions
- Build CI/CD pipelines for LLM-based systems with cost, latency, and throughput optimization

**AI System Design**
- Architect scalable, cloud-native AI platforms for high availability and fault tolerance
- Design for multi-tenant enterprise workloads with secure model access and governance
- Apply distributed systems principles to AI workloads

**Problem Solving &amp; OSS Mindset**
- Break ambiguous business problems into measurable ML / AI objectives
- Build reusable abstractions, not one-off solutions
- Contribute through open-source projects, reference architectures, and technical write-ups
